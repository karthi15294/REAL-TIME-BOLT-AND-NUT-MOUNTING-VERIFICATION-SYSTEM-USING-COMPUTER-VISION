Real-Time Bolt and Nut Mounting Verification System Using Computer Vision

Project Overview

A computer vision-based inspection system designed to automatically detect and verify the presence and mounting condition of bolts and nuts in real time, reducing manual inspection and improving assembly quality.

Objectives

- Detect bolts and nuts automatically
- Verify correct mounting during assembly
- Reduce manual inspection
- Improve inspection accuracy
- Enable real-time quality monitoring

Key Features

- Real-time image processing
- Automatic bolt and nut detection
- Computer vision-based inspection
- Assembly verification
- Automated quality checking
- Visual inspection results

Methodology

1. Capture the assembly image using a camera
2. Preprocess the captured image
3. Detect bolts and nuts using computer vision
4. Identify their position and presence
5. Compare the detected components with the required assembly condition
6. Verify correct mounting
7. Display the inspection result
8. Identify missing or incorrectly mounted components
9. Record the inspection outcome

Materials & Components

- Camera
- Computer/Laptop
- Python
- OpenCV
- Image processing software
- Bolt and nut assembly samples

Expected Outcome

The system aims to provide fast and reliable real-time verification of bolt and nut mounting, reducing human errors and improving quality control in manufacturing and assembly processes.

Future Scope

- AI-based object detection
- Deep learning integration
- Automated defect classification
- Industrial camera integration
- Robotic inspection
- IoT-based production monitoring
